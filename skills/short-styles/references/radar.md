# radar: the original launch-film look

**Feels like:** a cinematic launch film: drifting colour blobs, film grain, frosted glass cards, light leaks and sparks on every hit.
**Use for:** visual products that don't fit another style, or to break up a run of styled episodes.

**Look:** the palette rotates by episode (`ember`, `signal`, `ultraviolet`, `ice`, `paper`), or set `palette`. With `productColors: true` the product's own brand colours are used. Fonts come from `brand.font`/`displayFont`. Captions use the accent pill.

**Beat sheet:** the proven structure from `skills/launch-video/SKILL.md` (hook → screenshot/spotlight → features or steps → stat → cta) using any shared scene.
